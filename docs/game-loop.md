# ゲーム進行とループ

## 1プレイの流れ

```text
職種選択
  ↓
会社選択
  ↓
初期デッキ決定
  ↓
1日目の障害対応
  ↓
報酬・カード獲得
  ↓
翌日へ
  ↓
7日ごとの週次イベント
  ↓
残留・転職・休暇・昇進
  ↓
体力または信用が0になるまで継続
  ↓
結果表示・恒久強化
```

## 1日の進行

### 1. 出勤

曜日、会社効果、その日の特殊条件を決定します。

### 2. 障害発生

1件以上の障害が出現します。障害は耐久値と固有効果を持ちます。

### 3. カード戦闘

集中力を消費してカードを使います。障害を残してターンを終えると、体力や信用へ被害を受けます。

### 4. 退勤

すべての障害を解決すると報酬を選び、翌日に進みます。

報酬候補：

- カードを1枚獲得
- カードを1枚強化
- カードを1枚削除
- 体力を回復
- 信用を回復

## 曜日システム

| 曜日 | 傾向 |
|---|---|
| 月曜日 | 前週から残った障害や引き継ぎ問題 |
| 火曜日 | 標準的な障害 |
| 水曜日 | 会議、仕様変更、進捗確認 |
| 木曜日 | 納期直前で障害数が増える |
| 金曜日 | 障害が強化され、デプロイ事故が増える |
| 土曜日 | 障害は少ないが人員不足。低確率で重大障害 |
| 日曜日 | 回復・整理、または強大な緊急障害 |

## 金曜日

金曜日は週の山場です。

- 障害の耐久値が上昇
- 危険カードの副作用が増加
- デプロイ系障害の出現率が上昇
- 低確率で追加障害が発生

## 土日

土日は毎回ランダムに傾向を決めます。

### 平穏

- 障害数が少ない
- 回復やデッキ整理が可能
- 一部の担当者カードが使えない

### 緊急

- 強大な障害が1件発生
- 解決すると高品質な報酬を獲得
- 失敗時の被害が大きい

## 7日ごとの週次イベント

日曜日を終えると、次の行動を選びます。

### 残留

現在の会社への適応度が上がり、会社固有の強化を獲得します。

### 転職

提示された会社候補から次の勤務先を選びます。転職時には体力回復などの利点と、引き継ぎ不足などの欠点が発生します。

### 休暇

強化機会を一部失う代わりに、体力と信用を大きく回復します。

### 昇進・研修

条件を満たしている場合、職種効果やカードを強化します。

## ゲームオーバー

以下のいずれかで終了します。

- 体力が0になる
- 信用が0になる
- 特殊な重大障害への対応に失敗する

終了時に連勤日数を記録し、経験知を獲得します。

## 恒久強化

恒久強化は単純な数値上昇よりも、選択肢の解放を中心にします。

- 新職種
- 新カード
- 新会社イベント
- 初期デッキ候補
- 福利厚生
- 高難易度モード

周回後も判断が残るよう、恒久強化だけで難易度を無効化しない設計にします。
