# ゲームループ

## 1プレイの流れ

```text
監視開始
  ↓
検索条件を表示
  ↓
ログが下方向へ流れる
  ↓
条件一致行をタップ
  ↓
正解なら得点・コンボ・難易度進行
  ↓
誤検知または見落としでライフ減少
  ↓
ログ速度が徐々に上昇
  ↓
ライフ0で監視終了
```

## ライフ

- 初期ライフは3
- 誤ったログをタップすると1減少
- 条件一致ログが画面外へ流れると1減少
- ライフが0になるとゲームオーバー
- MVPではライフ回復を実装しない

時間制限は設けません。プレイヤーが対応可能な限り継続します。

## ログ速度

ログ速度はプレイ中に継続的に上昇します。

```text
速度倍率 = 1.0
  + ログ出現数による補正
  + 問題レベルによる補正
```

- 開始時は1.0倍
- 長くプレイするほどログの移動速度と出現間隔が短くなる
- 最大速度はMVPでは3.2倍
- 1.3、1.6、2.0、2.5、3.0倍付近で速度上昇演出を表示
- 速度上昇中もログ行のタップ高と文字サイズは維持する

## 正解

1. 対象ログをタップ
2. ログ行を分解・消滅
3. 得点とコンボを加算
4. 検索条件の達成数を更新
5. 規定数を発見すると次の条件へ移行

得点はコンボ、問題レベル、速度倍率によって増加します。

## 誤検知

条件に一致しない行をタップした場合：

- ライフを1失う
- コンボを0へ戻す
- 行と画面を振動させる
- `FALSE POSITIVE`を表示

## 見落とし

条件一致行が画面外へ流れた場合：

- ライフを1失う
- コンボを0へ戻す
- 赤い粒子と被弾演出を表示
- `MISSED`を表示

## 検索条件の進行

1. ERROR
2. WARN
3. ERRORかつpayment
4. status 500
5. timeout
6. ERRORかつauth
7. REQ=A82F
8. `payment`に似た`payrnent`

最終条件到達後も同条件を継続し、速度だけが上昇します。

## チュートリアル

- 説明画面を挟まない
- 開始直後の正解ログを発光させる
- 指マークを対象行へ表示する
- 最初の正解後に通常プレイへ移行する

## 一時停止

- ログ生成を停止する
- 画面上のログアニメーションをCSSで停止する
- 再開後は同じ状態から継続する

## 結果

- 最終スコア
- 最大コンボ
- 発見件数
- 正解率
- 最高速度

最高スコアはLocalStorageへ保存します。
