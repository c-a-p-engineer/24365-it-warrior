# ゲーム進行と戦闘ループ

## 1プレイの流れ

```text
メインキャラクター選択
  ↓
会社選択
  ↓
職位に応じた支援キャラクター編成
  ↓
1日最大4ターンの障害対応・会社業務
  ↓
翌日へ進行
  ↓
7日ごとの残留・転職・昇進・支援交代
  ↓
体力・信用・重大障害失敗まで継続
  ↓
職務経歴書と最高連勤記録を保存
```

## 1日4ターン

| ターン | 時間帯 | 主な特徴 |
|---:|---|---|
| 1 | 出勤時 | 障害発生、自動調査、初動対応 |
| 2 | ランチ | 支援・相談・追加調査に向く |
| 3 | 定時後 | 疲労が増えるが継続対応可能 |
| 4 | 深夜対応 | 最終対応。持ち越し不可障害が残ると敗北 |

各ターンは原則として次の順で処理します。

1. 手札からカードを1枚使う
2. 使用カードを捨て札または山札へ戻す
3. カードを1枚補充する
4. 未解決障害が行動する
5. 次の時間帯へ進む

カードを使わず、手札を1枚交換して次へ進むこともできます。

## 障害の表示と調査

障害の名前、危険度、持ち越し可否は表示します。原因と属性は能力判定で開示します。

```text
職種の専門能力が必要値以上
  → 確定開示

専門能力が必要値未満
  → 能力差に応じて確率開示

調査能力が調査難易度以上
  → 専門外でも確定開示

調査カードを使用
  → 戦闘中に追加開示
```

## カード対応

障害属性とカードカテゴリが一致すると、沈静化に必要な対応値を減らします。

原因未特定の場合：

- カード効果が低下する
- 最適対応は表示されない
- 解決しても原因不明として記録される

誤ったカードの場合：

- 原則として沈静化しない
- 障害の危険度が上昇する
- AIコード生成などの危険カードは上昇量が大きい

## 複数障害・複数属性

1日に複数の障害が同時発生します。障害1件が複数属性を持つ場合があります。

例：AI生成コードによる情報漏洩

- AI
- プログラミング
- 顧客・炎上

いずれかの有効属性へ対応すれば沈静化できますが、原因特定済みの最適カードが最も効率的です。

## 障害の持ち越し

### 持ち越し可能

翌日に残ります。ただし次のペナルティがあります。

- 危険度上昇
- 必要対応値増加
- 翌日の新規障害と同時に残る

例：軽微なUIバグ、技術的負債、API応答遅延、引き継ぎ不足。

### 持ち越し不可

4ターン終了時に残っていると即ゲームオーバーです。

例：本番DB停止、DNS障害、情報漏洩、決済停止、重大炎上。

## 早期解決後の選択

障害をすべて解決した時点で次のいずれかを選べます。

### 退勤

残りターン数に応じて体力を回復し、その日を終了します。

### 会社業務

余ったターンを消費して会社を強化します。

- 開発
- 採用
- 営業
- 業務改善

会社業務を選ぶと早期退勤回復を失います。

## 曜日システム

| 曜日 | 傾向 |
|---|---|
| 月曜日 | 前週から持ち越した障害と引き継ぎ問題 |
| 火曜日 | 標準的な障害 |
| 水曜日 | 会議、仕様変更、進捗確認 |
| 木曜日 | 納期前で障害数が増える |
| 金曜日 | 障害数・必要対応値・危険度が上昇 |
| 土曜日 | 平穏になりやすいが、低確率で重大障害 |
| 日曜日 | 会社業務・回復の機会、または強大な緊急障害 |

## 7日ごとの週次イベント

### 残留

現在の会社の信用・適応度が上がります。

### 転職

新しい会社へ移動し、勤務経歴へ記録します。SESは転職・現場移動が発生しやすくなります。

### 昇進

連勤日数と実績に応じて職位が上がります。

| 職位 | 支援枠 |
|---|---:|
| 新人 | 0 |
| 一般社員 | 1 |
| リーダー以上 | 2 |

### 支援キャラクター交代

解放済みの候補から最大2名を編成します。MVPでは未実装です。

## ゲームオーバー

- 体力が0：過労による休職
- 信用が0：契約終了・解雇
- 持ち越し不可障害を残す：重大障害対応失敗
- 自主退職を選ぶ

- 4ターン制
- 持ち越し判定
