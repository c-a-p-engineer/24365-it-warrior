# ゲームループ

## 1プレイの流れ

```text
監視開始
  ↓
検索条件を確認
  ↓
流れるログから一致行をタップ
  ↓
正解：得点・コンボ上昇
誤検知／見落とし：炎上度上昇
  ↓
規定数を発見すると条件変更・高速化
  ↓
時間切れまたは炎上度100
  ↓
調査報告書を表示
  ↓
即リトライ
```

## ログ生成

- ログ行は画面上部から下部へ常時移動する
- 1行は時刻、レベル、サービス、状態、HTTPステータス、リクエストIDで構成する
- 1行はスマートフォンで1行表示できる長さを目標とする
- 正解行は約26%を基準に生成する
- 難易度上昇で生成間隔と移動速度を上げる

例：

```text
12:04:14 ERROR payment timeout 500 REQ=A82F
```

## 正解判定

現在の検索条件を構成する文字列が、ログ本文にすべて含まれていれば正解です。

例：`ERROR + payment`

- `ERROR payment failed`：正解
- `ERROR auth failed`：不正解
- `WARN payment timeout`：不正解

## 正解時

1. ログ行を分解・縮小して消す
2. タップ位置に得点を表示する
3. コンボを1増やす
4. エンジニアが成功リアクションを行う
5. 規定数へ到達したら次の条件へ進む

## 誤検知時

- コンボを0へ戻す
- 炎上度を12上げる
- 対象行を赤く振動させる
- ノイズを表示する
- エンジニアが失敗リアクションを行う

## 見落とし時

正解行が画面外へ流れた時点で見落としと判定します。

- コンボを0へ戻す
- 炎上度を18上げる
- 画面を揺らす
- 炎色の粒子を表示する
- エンジニアをパニック状態にする

## コンボ

| コンボ | 演出 |
|---:|---|
| 5 | コンボバナー、粒子 |
| 10 | エンジニア覚醒、画面オーラ |
| 20以上 | `HUMAN GREP MODE` |

コンボは得点だけでなく、画面状態を段階的に変えるために使用します。

## ターゲット進行

各ターゲットには必要発見数とログ速度があります。

- 序盤：単一文字列
- 中盤：2条件
- 後半：ID一致、類似文字
- 最終条件をクリアすると制限時間を8秒追加し、周回する

## ゲーム終了

- 制限時間が0になる
- 炎上度が100になる
- プレイヤーが一時停止メニューから終了する

## セーブ

LocalStorageへ次を保存します。

- 最高スコア
- 最大コンボ
- 発見件数
- 正解率
