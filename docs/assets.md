# 素材台帳

この資料は、**24365 IT戦士 ― 目grep**で使用する画像・音声・UI素材が仮置きか本番用かを追跡します。

## ステータス

| 状態 | 意味 |
|---|---|
| `未着手` | 仕様のみ |
| `仮置き` | 文字、絵文字、CSSで代用中 |
| `確認待ち` | 候補作成済み |
| `本番` | 採用済み |
| `差替予定` | 現在使用中だが交換予定 |

## 共通アート方針

- コンセプト：暗い監視端末に明るいシアンの走査線
- 雰囲気：緊張感はあるが、怖すぎないポップなIT表現
- 背景：濃紺、黒、低彩度ブルー
- 通常強調：シアン
- 成功：緑
- 注意：黄
- 失敗・炎上：赤
- 生成画像へ文字を焼き込まない
- スマートフォン320px幅で識別できるシルエットを優先する

## 差し替えルール

1. 本番素材追加時にこの台帳を更新する
2. ファイル名は英小文字・数字・ハイフンのみ
3. 透過素材へ背景を焼き込まない
4. キャラクター差分は顔、髪、服、配色を固定する
5. 320px幅と低い画面で表示確認する
6. 音声追加時はミュート・音量設定を実装する
7. 演出素材はログ本文の可読性を下げない
