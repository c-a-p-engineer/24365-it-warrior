# 素材台帳

この資料は、ゲームで使用する画像・音声・UI素材について、**仮置きか本番用か**を追跡するための台帳です。

## ステータス定義

| ステータス | 意味 |
|---|---|
| `未着手` | 仕様のみ。ファイル未作成 |
| `仮置き` | CSS、文字、簡易SVGなどで代用中 |
| `確認待ち` | 本番候補を作成済み。採用判断が必要 |
| `本番` | 採用済み。ゲーム内で使用可能 |
| `差替予定` | 現在使用中だが、本番前に交換する |

## 共通アート方針

- 表現：現代的なITオフィスを題材にした、デフォルメ2Dイラスト
- 雰囲気：ダークな管理画面を基調に、ネオン過多にしない
- 主背景色：濃紺・ブルーグレー
- 強調色：シアン
- 警告色：黄
- 危険色：赤
- キャラクターは背景と分離できる輪郭と明暗差を持たせる
- 生成画像内に文字を入れない。文字はHTML/CSSで表示する
- GitHub Pages向けに、原則としてPNGまたはWebPを使用する

## 差し替えルール

1. 本番素材を追加したら、この台帳の状態を更新する。
2. ファイル名は英小文字・数字・ハイフンのみを使用する。
3. 透過が必要な素材に白背景を焼き込まない。
4. 同一キャラクターは髪型、服装、配色、顔立ちを固定する。
5. 画像追加後はPC幅と320px幅の双方で表示確認する。
6. 音声追加後はミュート設定と音量設定を必ず実装する。
