# 素材台帳

この資料は、**24365 IT戦士 ― バグマージ**で使用する素材が仮置きか本番用かを追跡する台帳です。

## ステータス

| ステータス | 意味 |
|---|---|
| `未着手` | 仕様のみ。ファイル未作成 |
| `仮置き` | 絵文字、CSS、文字で代用中 |
| `確認待ち` | 本番候補を作成済み |
| `本番` | 採用済み |
| `差替予定` | 使用中だが交換予定 |

## アート方針

- コンセプト：暗い運用端末とポップなバグタイル
- 背景：濃紺、黒に近いブルー
- 通常強調：シアン
- 成功：緑
- 警告：黄
- 危険：赤
- 小さなスマートフォンでもシルエットでレベル判別できること
- 生成画像内へ文字を入れない
- UI文字はHTML/CSSで表示する
- GitHub Pages向けにWebP、透過が必要ならPNGまたはSVGを使う

## 差し替えルール

1. 本番素材を追加したら台帳を更新する
2. ファイル名は英小文字・数字・ハイフンのみ
3. 透過素材へ背景色を焼き込まない
4. 320px幅で各バグレベルを判別できること
5. 音声追加時はミュート設定を同時実装する
6. 画像追加後も初回ロードを可能な限り5MB以下へ維持する
