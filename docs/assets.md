# 素材台帳

この資料は、ゲームで使用する画像・音声・UI素材について、**仮置きか本番用か**を追跡するための台帳です。

## ステータス定義

| ステータス | 意味 |
|---|---|
| `未着手` | 仕様のみ。ファイル未作成 |
| `仮置き` | CSS、絵文字、文字、簡易SVGなどで代用中 |
| `確認待ち` | 本番候補を作成済み。採用判断が必要 |
| `本番` | 採用済み。ゲーム内で使用可能 |
| `差替予定` | 現在使用中だが、本番前に交換する |

## 共通アート方針

- コンセプト：**ポップなITオフィス × 炎上シミュレーション**
- 表現：現代的なITオフィスを題材にしたデフォルメ2Dイラスト
- 雰囲気：明るく読みやすいが、障害時には警告色と表情で緊迫感を出す
- 背景色：白、薄いブルーグレー、低彩度のオフィス色
- 強調色：青
- 警告色：橙
- 危険色：赤
- キャラクターは太すぎない輪郭と明確なシルエットを持たせる
- 生成画像内に文字を入れない。文字はHTML/CSSで表示する
- GitHub Pages向けに、原則としてWebP、透過が必要な場合はPNGを使用する
- PC表示だけでなく320px幅で判別できる構図にする

## 音声素材

## 差し替えルール

1. 本番素材を追加したら、この台帳の状態を更新する。
2. ファイル名は英小文字・数字・ハイフンのみを使用する。
3. 透過が必要な素材に白背景を焼き込まない。
4. 同一キャラクターは髪型、服装、配色、顔立ちを固定する。
5. 画像追加後はPC幅、640px幅、320px幅で表示確認する。
6. カード画像は縮小時にも主要モチーフが中央で判別できる構図にする。
7. 音声追加後はミュート設定と音量設定を必ず実装する。
