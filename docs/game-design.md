# ゲーム企画概要

## タイトル

**24365 IT戦士 ― 目grep**

## コンセプト

大量に流れる短いログから、画面上部の検索条件に一致する行を見つけてタップする高速探索ゲームです。

ITスラングの「目grep」を、説明なしでも理解できるスマートフォン向けの反射・識別ゲームへ変換します。

## 設計目標

- スマートフォン縦画面
- タップのみで操作
- ページスクロールなし
- 1プレイ約1〜3分
- 最初の数秒でルールを理解できる
- 常に何かが動いている
- IT知識がなくても文字や色の一致で遊べる

## 基本ルール

1. `FIND` に検索条件が表示される
2. ログ行が上から下へ流れる
3. 条件に一致する行をタップする
4. 正解すると得点とコンボを得る
5. 誤った行を押すと誤検知になる
6. 正解行を画面外へ流すと見落としになる
7. 誤検知・見落としで炎上度が上がる
8. 炎上度100、または制限時間終了でゲーム終了

## 説明なしの導線

最初の正解行は次の方法で示します。

- 対象行が発光する
- 指アイコンが対象行を指す
- タップ成功時に大きく `GOOD!` を表示する

説明文を読ませるチュートリアル画面は設けません。

## 検索条件

難易度に応じて順番に追加します。

| 段階 | 例 |
|---:|---|
| 1 | `ERROR` |
| 2 | `WARN` |
| 3 | `ERROR + payment` |
| 4 | `500` |
| 5 | `timeout` |
| 6 | `ERROR + auth` |
| 7 | `REQ=A82F` |
| 8 | `payrnent` と `payment` の識別 |

通常プレイの複合条件は最大2つまでとします。

## スコア

- 正解：基本点＋コンボ補正＋難易度補正
- 連続正解：コンボ上昇
- 誤検知：コンボ0、炎上度上昇
- 見落とし：コンボ0、誤検知より大きく炎上度上昇

## 結果表示

- スコア
- 最大コンボ
- 発見件数
- 正解率
- ITネタの総評

総評例：`grepを使えばもっと早かった。`

## 対象環境

- GitHub Pages
- スマートフォン縦画面優先
- PCブラウザ対応
- 1人プレイ
- ネットワーク対戦なし
- 外部APIなし
- LocalStorageセーブ
