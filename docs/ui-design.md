# UI/UXデザイン方針

## コンセプト

**ポップなITオフィス × 炎上シミュレーション**

会社経営シミュレーション、障害対応カードゲーム、キャラクター育成の3要素が一目で分かる画面を目指します。

## デザイン原則

1. 最優先情報は「現在の障害」と「使えるカード」
2. メインキャラクターと支援キャラクターを常時表示する
3. カードはカテゴリ、出力、効果、危険性を見ただけで判別できる形にする
4. 本物の業務管理画面には寄せすぎず、ゲームとしての視認性を優先する
5. PCとスマートフォンで操作方法を変えず、タップだけで完結させる

## 画面構成

### PC

- 上部：曜日、連勤日数、会社、4ターンの進行
- 左：メインキャラクター、支援枠、体力、信用、職位
- 中央：複数の障害カード
- 下部：手札
- 最下部：折りたたみ式の対応ログ

### スマートフォン

- 縦一列を基本とする
- チーム情報を障害より上に配置する
- 障害は1列表示
- 手札は画面下へ固定する
- 手札は横スワイプで閲覧する
- カードをタップした後、対象障害をタップして使用する
- 最小対応幅は320px

## カードデザイン

カード比率は概ね縦長の3:4とします。

表示要素：

- 右上：出力値
- 上半分：カテゴリ共通イラスト
- 中央：カテゴリ名とカード名
- 下部：短い効果説明
- 危険カード：赤い警告リボン

カテゴリカラー：

| 分類 | 色 |
|---|---|
| プログラミング | 青 |
| インフラ | 紫 |
| 顧客 | 橙 |
| AI | 水色 |
| 管理 | 緑 |
| 危険対応 | 赤い警告を追加 |

## 障害デザイン

障害も敵カードとして表現します。

- 障害名とカテゴリを上部に表示
- 危険度を数値と色の両方で表示
- 原因、持ち越し可否、判明属性を表示
- 沈静化の進捗をゲージ表示
- 選択したカードを使用可能な場合は「タップして使用」と表示

## キャラクター表示

本番素材が完成するまでは絵文字を仮置きします。

- メインキャラクター：胸上または腰上の立ち絵
- 支援キャラクター：顔から胸上のアイコン
- 疲労、炎上、深夜対応などは将来的に表情差分で表現
- キャラクター画像内には文字を入れない

## 操作

1. 手札のカードをタップ
2. 選択中カードが浮き上がる
3. 使用対象の障害をタップ
4. カードを消費して結果を表示

ドラッグ操作は必須にしません。スマートフォンのスクロールと衝突するためです。

## アクセシビリティ

- 色だけで状態を区別しない
- ボタンのタップ領域は44px以上
- 本文は原則14px以上
- 横スクロールは手札だけに限定
- 無音でも全情報を理解可能にする
