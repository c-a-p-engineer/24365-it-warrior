# 24365 IT戦士 ― 目grep

大量に流れる短いログから、検索条件に一致する行を見つけてタップする短時間ブラウザゲームです。

## 遊ぶ

**GitHub Pages:** https://c-a-p-engineer.github.io/24365-it-warrior/

## ゲーム概要

- スマートフォン縦画面・片手タップ操作
- ページスクロールなしの1画面構成
- 流れるログから指定された文字列・複合条件を探す
- 正解でログが分解・消滅し、コンボとスコアが上昇
- 誤検知・見落としで炎上度が上昇
- 炎上度100、または制限時間終了で監視終了
- 最初の対象行を光らせ、説明を読まずに操作を理解できる導線
- 条件は `ERROR` から始まり、複合検索・類似文字へ難化
- LocalStorageへ最高スコア、最大コンボ、正解率を保存

## 操作

1. 上部の `FIND` 条件を見る
2. 条件に合うログ行をタップ
3. それ以外の操作は不要

## 主なアニメーション

- ログの常時スクロール
- 正解行の分解・粒子消滅
- 誤検知時のノイズ・振動
- 見落とし時の炎上演出
- コンボ段階による画面覚醒
- エンジニアの表情・リアクション
- ターゲット変更、時間切れ、結果画面の演出
