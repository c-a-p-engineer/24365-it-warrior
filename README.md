# 24365 IT戦士

24時間365日、IT企業のタスクを処理し続けるローグライト型カードゲームです。

プレイヤーはエンジニアとして勤務先を選び、常に発生している複数のタスクへ適切な対応カードを使用します。1ステージは1日、ハイスコアは「何連勤できたか」を職務経歴書風に表示します。

## 遊ぶ

**GitHub Pages:** https://c-a-p-engineer.github.io/24365-it-warrior/

> 初回公開時は Settings → Pages → Source を **GitHub Actions** に設定する必要がある場合があります。

## 現在のゲーム設計

- 戦闘画面はスクロールなしの1画面固定
- PC・スマートフォンの表示領域内にHUD、タスク、手札を配置
- スマートフォンではタスクと手札を横スワイプ
- ゲーム開始時は勤務先のみ選択し、エンジニアとして入社
- タスクと対応方法の両方を縦長カードとして表示
- 各タスクカードに納期、危険度、属性、原因、進捗を表示
- 納期はランチ、定時、深夜、翌日以降で設定
- 納期超過したタスクが残るとゲームオーバー
- タスクは常に2件以上存在し、完了すると追加タスクが割り込む
- タスク例：開発、バグ修正、クラウド運用、顧客説明、採用、営業、引き継ぎ、炎上対応
- タスクは複数属性を持つ
- 能力値と調査能力によって原因・属性を開示
- 誤ったカードを使うと危険度が上昇
- 原因不明のまま完了することも可能
- 1日4ターン：出勤、ランチ、定時後、深夜
- 7日ごとに残留・転職イベント
- 職務経歴書風の結果表示
