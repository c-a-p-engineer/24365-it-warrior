# 24365 IT戦士 ― バグマージ

同じ深刻度のバグをスワイプで統合し、本番障害になる前にパッチで除去する短時間ブラウザゲームです。

## 遊ぶ

**GitHub Pages:** https://c-a-p-engineer.github.io/24365-it-warrior/

## ゲーム概要

- スマートフォン縦画面を優先した4×4マージパズル
- 上下左右のスワイプで同じバグを統合
- マージするとバグの深刻度と得点が上昇
- マージによって得たパッチを使い、任意のバグを除去
- 緊急・本番障害を盤面に残すと本番安定度が低下
- 本番安定度が0、または盤面が詰まるとゲームオーバー
- 10操作ごとに1日進み、何連勤できたかを記録
- 5日ごとの金曜日は安定度への負荷が増える
- 勤務先によって初期安定度、パッチ数、バグ発生傾向、得点倍率が変化

## 勤務先

| 勤務先 | 特徴 |
|---|---|
| 大企業 | 安定度と初期パッチが多い初心者向け |
| SES | 大きなバグが出やすい代わりに得点倍率が高い |
| 受託開発 | 安定度は低いが初期パッチが多い短期決戦型 |
| 自社サービス | 連続マージによるコンボ得点が高い |

## 操作

- スマートフォン：盤面を上下左右へスワイプ
- PC：矢印キー、または画面下の方向ボタン
- パッチ適用：ボタンを押した後、除去するバグをタップ
