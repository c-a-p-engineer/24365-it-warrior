# 24365 IT戦士

24時間365日、IT障害と戦い続けるローグライト型カードゲームです。

職種と勤務先を選び、毎日発生する障害をカードで解決します。1ステージは1日として進行し、体力や信用が尽きるまでの「連勤日数」がハイスコアになります。

## ゲーム概要

- ブラウザで遊べる1人用カードゲーム
- 1ステージ＝1日
- 月曜日から日曜日まで曜日ごとの特徴あり
- 金曜日は障害が強化
- 土日は平穏または強大な緊急障害が発生
- エンジニア、PMなどの職種ごとに固有効果あり
- 大企業、SES、受託、自社サービスで会社傾向が変化
- 7日ごとに残留・転職などを選択
- ゲームオーバー後に恒久強化して再挑戦
