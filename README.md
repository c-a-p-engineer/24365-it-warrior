# 24365 IT戦士

24時間365日、IT障害と戦い続けるローグライト型カードゲームです。

職種と勤務先を選び、毎日発生する複数の障害をカードで沈静化します。1ステージは1日、ハイスコアは「何連勤できたか」を職務経歴書風に表示します。

## 遊ぶ

**GitHub Pages:** https://c-a-p-engineer.github.io/24365-it-warrior/

> Pagesの初回公開には、リポジトリの Settings → Pages で Source を **GitHub Actions** に設定する必要がある場合があります。

## デザインコンセプト

**ポップなITオフィス × 炎上シミュレーション**

- 会社経営シミュレーション、障害対応カードゲーム、キャラクター育成を一画面で表現
- メインキャラクターと支援枠を常時表示
- 障害を敵カード、対応方法を縦長の手札カードとして表示
- スマートフォンでは手札を画面下へ固定し、横スワイプで操作
- カードをタップしてから対象障害をタップするタッチ優先操作

## 現在遊べる内容

- メインキャラクター選択：エンジニア、PM、インフラエンジニア、QAエンジニア
- 会社選択：大企業、SES、受託開発、自社サービス
- 複数障害と複数属性
- 能力値・調査能力による原因と属性の開示
- 誤ったカードによる危険度上昇
- 原因不明のまま障害を解決する「なぜか直った」記録
- 出勤時、ランチ、定時後、深夜対応の最大4ターン
- 持ち越し可能／当日解決必須の障害
- 障害がない時間帯の開発、採用、営業、業務改善
- 7日ごとの残留・転職イベント
- LocalStorageによる最高記録保存
- 職務経歴書風の結果表示
