# 24365 IT戦士 ― 目grep

流れ続けるログから検索条件に一致する行を見つけ、タップするスマートフォン向け高速探索ゲームです。

## 遊ぶ

**GitHub Pages:** https://c-a-p-engineer.github.io/24365-it-warrior/

## ゲーム概要

- スマートフォン縦画面・1画面固定
- 操作はログ行のタップのみ
- 最初の対象行を発光と指マークで案内
- 誤タップまたは対象ログの見落としでライフを1失う
- 初期ライフは3
- 時間制限なし。ライフが尽きるまで継続
- プレイの進行と難易度に応じてログの移動・出現速度が徐々に上昇
- ERROR、WARN、複合条件、ステータスコード、ID、類似文字へ段階的に難化
- 正解で得点とコンボを獲得
- 最高速度、得点、最大コンボ、発見件数、正解率を記録
- LocalStorageへ最高記録を保存

## 操作

1. 画面中央の検索条件を見る
2. 条件に一致するログ行をタップする
3. 誤った行を押さず、対象行を画面外へ逃さない

説明を読まなくても遊べるよう、開始直後は正解行を発光させます。

## 難易度上昇

- ログの出現回数と問題レベルから速度倍率を算出
- 開始時は1.0倍
- 長く継続するほど最大3.2倍まで加速
- 一定速度へ到達すると画面演出で通知
- 後半は複合条件や類似文字判定が増える
